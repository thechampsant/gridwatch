    How the data gets to this screen

    1. The charging network reports in. Each operator's charger-management system (the vendor) sends status changes in batches up to a minute apart. Each charger takes a power reading about every 10 seconds, but the vendor lets us collect them at most every 30 seconds per site. So they arrive about three at a time: we keep every reading, and the newest can be up to about 40 seconds old.
    2. Every update is checked. Repeats are ignored, an older update never overwrites a newer one, and a broken record is set aside without losing the rest of its batch.
    3. It is stored per operator. One operator can never see another's data; the database itself enforces it.
    4. It reaches the screen in about a second. Each change is pushed to open dashboards as soon as it is stored, and the page times how long it took to draw. Most of the delay you see comes before the data reaches us. The panels below show both parts separately.
